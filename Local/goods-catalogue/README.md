Item summary now includes sortable Max gain and Max loss columns, per traded unit in credits and percentage of the relevant purchase price. Gain=max(0,highSell-lowBuy); loss=min(0,lowSell-highBuy). Missing either side is N/A. No-profit/no-loss cases show 0 without an invented extreme-event frequency. The cycle projector counts exact extrema occurrences alongside its existing bounds pass. Exchange quote-pair frequency is the product of the endpoint frequencies, assuming two independent uniform station/day selections: listed exchanges for buy, accepting exchanges for sell, 1,440 phases each. It excludes journey feasibility, costs, stock, access and random trader availability. Mixed-channel aggregate bounds get a frequency only if both extrema actually occur in the exchange sample. Restricted/fixed non-exchange items remain N/A. Counts are four integers per exchange row, avoiding histograms, extra engine work in the browser, or game changes. Summary CSV includes all gain/loss and probability fields; probabilities are fractions in [0,1].

Typical quote-pair averages supersede the proposed decile averages after user clarification. Avg gain is the mean of all positive exchange margins; Avg loss the mean of all negative margins, each with arithmetic mean pair ROI. Gain/loss frequencies use all pairs in the denominator, retaining break-even pairs separately. Conditional means with no outcomes are null while their probability is zero. Unsupported populations are null for both. The server gathers histograms in the existing quote pass and calculates exact weighted cumulative counts and sums without allocating Cartesian pairs. Compact precomputed source groups (all exchanges and the listed subset) reach the browser; group keys must match selected exchange rows exactly. Random travellers and restricted dealers are excluded. CSV includes both conditional means, both probabilities, break-even probability and unconditional expected margin/ROI. These describe uniform independent exchange station/day draws rather than actual journeys. No game or save changes.

The summary-only Return columns selector chooses Credits first or Return % first without adding table columns. Changing basis while a return column is sorted preserves its column and direction and maps to the matching percent/credit key. The selection and exact sort key persist in the URL and through the formulas-page return link. Reset restores Credits first. CSV always includes both numeric units and all probability fields.

The final summary column pools separate daily buy-price and sell-price histograms across the complete 1,440-day baseline cycle. Every eligible station-day counts once: buys at listed exchanges, sells at accepting exchanges. It uses 128 common price bins, mass-conserving local smoothing and shape-preserving interpolation. Exact unsmoothed quotes supply means, medians, extrema and population standard deviations. Tooltips expose marker values and empirical at/below and at/above shares. Curves always use credits; the Return selector affects the separate gain/loss columns. Quote-pair return statistics remain explicitly distinct from daily price frequencies and from feasible journey outcomes. Intermittent dealers contribute no invented daily observations.
